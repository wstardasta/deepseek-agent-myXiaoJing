# 小鲸 · 一个接在 QQ 上的 AI 智能体

> NapCat + DeepSeek 驱动的 QQ 机器人：有情绪、有记忆、会写日记、会自己找表情包。

## 特性

- **四维情绪**（开心度 / 精力 / 亲近感 / 不爽度），随时间衰减，被伤到会留下需要哄才消的"刺"
- **情绪识别**：规则层 + 小模型，认出对方 15 种情绪并决定怎么接
- **长期记忆**：她自己维护一本 markdown 笔记，分章节，每月把日记归档进「时间线」
- **私人日记**：每天固定时间写一篇，真实对话为骨架 + 一点情绪化想象
- **表情包**：自己上网找二次元梗图，按**她自己的心情**挑一张发出去，挑不到就不发
- **回复质检**：本地清洗占位符 / markdown / 破功句，零成本零延迟
- **缓存优化**：静态提示词与动态内容分离，上下文缓存命中率约 70%

## 目录结构

```
src/
  index.mjs     主程序（消息收发、提示词拼装、各功能调度）
  emotion.mjs   四维情绪状态机
  feeling.mjs   情绪识别（规则 + 模型两层）
  memory.mjs    长期记忆笔记（markdown）
  diary.mjs     日记生成与月度归档
  stickers.mjs  表情库管理（收集、分类、挑选）
  polish.mjs    回复质检（本地清洗）
```

## 快速开始

1. 安装 [NapCat](https://github.com/NapNeko/NapCatQQ) 并登录 QQ
2. 复制 `.env.example` 为 `.env`，填入 `OPENAI_API_KEY`、`AGENT_OWNER` 等
3. NapCat 里配一个反向 WebSocket，指向 `ws://127.0.0.1:16700/onebot/v11/ws`
4. `npm install && node src/index.mjs`

## 1. 她是什么

一个接在 QQ 上的 AI 智能体（NapCat + DeepSeek），叫小鲸，人设是"你亲手做出来的、活泼的邻家妹妹"。

她能做这些事：

- 私聊和群里聊天，有情绪、有记性、会撒娇、会开玩笑
- 每天写日记
- 自己维护一本关于你的记忆笔记
- 自己上网找二次元表情包，聊天时按心情发

---

## 2. 怎么用

### 私聊
直接说话就行，她一定回。

### 群里
**只有这三种情况她才说话：**

1. 有人 **@ 她**
2. 有人叫她的名字（欧鲸鲸 / 小鲸 / 鲸鲸）
3. 有人**回复**她发过的那条消息

其他时候她一律不插嘴——哪怕你在群里聊得热闹。

### 命令

| 发这个 | 她会 |
|---|---|
| `/ping` | 回一句"pong"，确认在线 |
| `/help` | 列一遍命令 |
| `/reset` | 忘掉当前会话的上下文 |
| `/日记` | 把今天的日记发给你（没写就发最近一篇） |

## 4. 三个核心功能怎么运作

### 📔 日记

```
你俩每说一句话 → 记进当天流水（daylog.json）
        ↓
每晚 22:30 之后，每 10 分钟检查一次
        ↓
今天聊够 3 条 → 写一篇 150~300 字
        ↓
存进 diary\日期.md
        ↓
她聊天时自动带最近 3 篇的摘要当背景
```

**内容规则**：以真实对话为骨架，允许一点情绪化想象，**不许编造事件**。

今天话太少就不写——不硬凑。

### 🧠 记忆

`memories.md` 是她自己维护的笔记，六个章节：

```
关于他 / 他的喜好 / 他的习惯 / 我们在做的事 / 我自己想记住的 / 时间线
```

- **每聊 6 轮**自动更新一次（合并、修正、删次要的）
- **上限 2000 字**，超了她自己会压缩
- 每月初把上个月的日记压成一段，接进「时间线」

💡 **你手动写进去的内容，她会当成自己记得的。**

### 🎨 表情包

```
① 种子：连上 QQ 时读一次你的「收藏表情」（只能读，写不进去）
② 自己找：每 5 分钟去百度图片搜一次，缺哪种情绪就搜哪种
③ 筛选：视觉模型看图 → 是不是二次元表情包？什么情绪？画面上写了啥
④ 使用：聊天时按**她自己的心情**挑一张，挑不到就不发
```

**关键：表情包配的是她自己此刻的心情，不是对方的情绪。**
比如你在骂人、她只是淡淡回一句，她会发「无语」而不是「生气」。

当前：**107 张，其中二次元 86 张**。

## 5. 参数怎么改

**全部在 `.env` 里改，改完必须重启。**

### 最常改的几个

| 参数 | 现在 | 作用 |
|---|---|---|
| `AGENT_SYSTEM_PROMPT` | 一大段 | **她的人设**。改这个比调任何参数都管用 |
| `AGENT_OWNER` | 你的QQ号 | 你的 QQ 号（创作者兼男朋友，只认这个号） |
| `AGENT_SELF_NAME` | 欧鲸鲸 | 她 QQ 的昵称（用来识别"有人在叫她"） |

### 表情包

| 参数 | 现在 | 作用 |
|---|---|---|
| `AGENT_STICKER` | on | 总开关，关掉就不发表情 |
| `AGENT_STICKER_RATE` | 0.5 | 每条回复后尝试带表情的概率 |
| `AGENT_STICKER_QUOTA` | 10 | 每种情绪目标张数（谁少先补谁） |
| `AGENT_STICKER_MAX` | 150 | 库里最多留几张，超了自动淘汰 |
| `AGENT_STICKER_WEB` | on | 自己上网找的开关 |
| `AGENT_STICKER_WEB_PER_RUN` | 3 | 每次找几张 |
| `AGENT_STICKER_COLLECT` | on | 收群里别人发的图 |

> 觉得表情太多/太少 → 调 `RATE`（0.2 很少，0.8 很频繁）
> 觉得老是同一种 → 调 `QUOTA`

### 日记

| 参数 | 现在 | 作用 |
|---|---|---|
| `AGENT_DIARY` | on | 总开关 |
| `AGENT_DIARY_HOUR` / `MINUTE` | 22 / 30 | 几点写 |
| `AGENT_DIARY_RECALL` | 3 | 聊天时带几篇旧日记（0 = 不带） |

### 记忆

| 参数 | 现在 | 作用 |
|---|---|---|
| `AGENT_MEMORY_MD` | on | 总开关 |
| `AGENT_MEMORY_MAX` | 2000 | 笔记字数上限 |
| `AGENT_MEMORY_UPDATE_EVERY` | 6 | 每聊几轮更新一次 |

### 群聊

| 参数 | 现在 | 作用 |
|---|---|---|
| `AGENT_GROUP_ONLY_WHEN_ADDRESSED` | **on** | **只在她被叫到时说话**（关掉就会乱插嘴，不建议） |
| `AGENT_ALLOWED_GROUPS` | 空 | 只在这些群工作，空 = 所有群 |
| `AGENT_MUTE_MINUTES` | 10 | 你说"闭嘴/安静"后静音多久 |

### 主动发消息

| 参数 | 现在 | 作用 |
|---|---|---|
| `AGENT_SELF_POST` | on | 她自己想到什么就发（6 条/天） |
| `AGENT_SELF_POST_DAILY_MAX` | 6 | 每天最多几条 |
| `AGENT_SELF_POST_GAP_MINUTES` | 90 | 两条之间至少隔多久 |
| `AGENT_PROACTIVE` | **off** | 定时问候（和上面重复，已关） |

### 省钱 / 提速

| 参数 | 现在 | 作用 |
|---|---|---|
| `OPENAI_MODEL` | deepseek-chat | 聊天用的模型 |
| `OPENAI_MAX_TOKENS` | 1200 | 单条回复上限 |
| `AGENT_THINKING` | off | 开成 on 会"想清楚"但更慢更贵 |
| `AGENT_HUMOR_RATE` | 0.5 | 多大比例带梗 |

## 6. 出问题怎么查

**先看日志**：`agent.log`，最后 20 行基本能看出问题。

| 现象 | 大概率原因 | 怎么办 |
|---|---|---|
| 她不回消息 | 没连上 NapCat | 日志找 `[onebot] connected`；没有就重启 NapCat |
| 回"钥匙不对" | API Key 失效 | 改 `.env` 的 `OPENAI_API_KEY` |
| 回"余额见底" | DeepSeek 没钱了 | 去平台充值 |
| 群聊完全不说话 | 没 @ 她 | 这是正常行为（见第 2 节） |
| 表情包不发了 | 候选都被判定不合适 | 正常——她宁可发也不硬凑 |
| 日记没写 | 那天聊得太少 | 聊够 3 条就行 |

**想深度排查**：`.env` 里把 `AGENT_DEBUG_GROUP=on`，日志会把真正塞给模型的群上下文原样打出来。

## 7. 不要动的东西

| 东西 | 为什么 |
|---|---|
| `node_modules\` | 依赖库，删了要重装 |
| `src\*.mjs` | 程序本体，改坏了会崩 |
| `.env` 里的 `OPENAI_API_KEY` | 泄露了别人能花你的钱 |
| `NapCat2\config\` | NapCat 的连接配置，改了她就接不上 QQ |

**可以随便改的**：`memories.md`（写你想让她记住的）、`diary\*.md`（改错别字）。

## 8. 一套完整的"改造她"流程

1. 改 `.env`（人设 / 参数）
2. 存盘
3. 双击 `重启小鲸.bat`
4. 看 `agent.log` 最后几行，确认 `功能开关:` 那行是你想要的
5. 去 QQ 试两句

启动日志长这样，一眼就能确认所有开关状态：

```
[agent] 功能开关: 对主人永远热情=开 · 群聊只在被叫时说话=开 · 主动私聊=关
       · 群主动开话题=关 · 自己发消息=开 · 自己发到群里=关
       · 回复质检=开 · 幽默=开 · 表情包=开(发出概率50%/收集开)
[sticker] 表情库: 共 107 张，已分类 107 张，其中二次元 86 张
[memory] 记忆笔记: ...\memories.md（414 字，上限 2000）
```
